# 教练 / AI 助手 · 功能验收标准 Spec（Acceptance Spec）

> 目标：为「**教练角色即 AI 助手**」这一核心定义提供**可判定、可复核**的验收标准。所有条目对齐 [PRD.md](../PRD.md) §15「AI 教练助手（统一角色）全维度能力设计」，本文件是其验收侧细化，不引入第二套定义。
> 角色唯一命名：**AI 教练助手**（简称「教练」，UI 短标签沿用「教练」）；分**教练面**（演练·辅导）与**助手面**（执行·问答）两个能力面。
> 范围声明：v1.0（配合 PRD v5.18.0）为**纯文档与设计**，未改动任何 `.mjs`/`.jsx`。故本 Spec 条目分两类验证方式：
> - **【文档】** 本版即可判定——指文档层的一致性、完备性、无冲突；
> - **【代码】** 属后续独立迭代的落地验收——标注**映射既有测试**（可复用的回归基线）或**待补测**（合流后需新增）。
> v1.1（配合 PRD v5.19.0）：**§6.2 代码级三步已全部落地**——system 角色合流（统一人设 `ROLE_LINE`）、回归不破坏、专项测试 U1-U3 新增；RC-3 升为代码级达标，G4 待清偿项清偿。
